# Contextory 0.2.6

Open a project and let Contextory prepare every detected native agent, with a footer switch to pause automatic setup.

- Detect installed Codex and Claude Code extensions and recognize IBM Bob. Configure all detected supported agents at early startup, before opening Contextory or starting a native session, and detect agents installed later.
- Keep **Auto-connect** enabled by default. Pause/resume from the footer, the Command Palette, or `contextory.autoConnect`; existing connections, sessions and project records remain available.
- Default `contextory.startupAgent` to `auto`. Fixed providers, `last-used` and `none` remain available, and a manually disconnected provider stays disabled until reconnected. Explicit settings from earlier versions remain in effect; select `auto` to prepare all detected agents.
- Keep tools discoverable while the workspace service starts. The proxy advertises the full catalog immediately and waits up to 15 seconds for readiness before executing a tool once. Existing bridges continue to follow rotated service descriptors.
- Serialize configuration changes and isolate provider errors so one conflicting file does not prevent another agent from being prepared.

Install `contextory-workspace-0.2.6.vsix` and reload the editor. Then open a trusted local folder with the supported native agents enabled. **Auto-connect** is in the footer in both sidebar and Panel layouts. The green light still means MCP traffic has been observed.

Native clients own MCP trust and session startup. Codex and Claude Code expose no public editor command to force MCP reload, so first-time setup in an already-running client may still need native approval or an extension/session restart. Contextory does not restart the editor or send chat prompts.

Validation: TypeScript checking, production builds, 41 backend tests and 20 Playwright tests, plus visual review of the footer in narrow, short and light-theme layouts. The extracted VSIX passed the full host checks in VS Code 1.145.3 and IBM Bob (VS Code API 1.126.0), including automatic discovery with inactive agent fixtures and persistent pause/resume. A separate packaged VS Code run verified a paused cold startup creates no provider configuration until resumed. Authenticated native chat and client trust/reload remain separate qualification steps.

This is a local package; no Marketplace publication or GitHub release was made.
