# Contextory v0.3.1

This patch updates release packaging and documentation publishing after [v0.3.0](v0.3.0.md). It includes the visual Code map and Architecture explorers, live codebase intelligence and portable agent workflow from that release.

## Changes

- Generate ASCII-safe documentation JavaScript so the complete site can pass repository scanning and deploy to GitHub Pages.
- Pin the documentation deployment action to its release commit for reproducible workflow configuration.
- Read the package version when generating documentation source links and verifying the live release page. Update current installation links and site navigation to 0.3.1.
- Repackage the extension as 0.3.1 with matching VSIX and SHA-256 release assets.

Browse the [complete searchable documentation](https://igormicadei.github.io/Contextory/) for guides, architecture, tools, skills and release history. The site is published from the independent `gh-pages` branch.

## Install or upgrade

1. Use Windows, Node.js **24+**, and VS Code **1.96+** or IBM Bob with one trusted local project folder.
2. Download `contextory-workspace-0.3.1.vsix` and `contextory-workspace-0.3.1.sha256` from the [GitHub release](https://github.com/igormicadei/Contextory/releases/tag/v0.3.1). Compare the VSIX SHA-256 with the checksum file.
3. Choose **Extensions → … → Install from VSIX…**, select the package, and reload the editor. VS Code users can also run `code --install-extension .\contextory-workspace-0.3.1.vsix`.

Existing Contextory records and schema 4 storage remain compatible. Back up authoritative editor or standalone storage before upgrading. Native agents are installed and authenticated separately; Python 3.10+ is required only for Python analysis. See the [user guide](../USER-GUIDE.md) and [0.3.0 upgrade notes](v0.3.0.md#upgrade-and-storage).

## Validation and limits

See the [validation record](../VALIDATION.md) for package inspection, automated checks and extracted-package checks in VS Code and IBM Bob. Static maps describe indexed relationships and possible paths, not observed execution or test coverage. Existing language, platform and authenticated-agent qualification limits continue to apply.

Distribution uses GitHub release assets. The project remains **UNLICENSED**.
