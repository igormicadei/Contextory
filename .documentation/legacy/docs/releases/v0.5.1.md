# Contextory v0.5.1

Click a gray native-agent connection button to retry setup without removing the existing configuration.

## Changes

- Fix the footer action for configured agents waiting for traffic: gray buttons retry setup; green buttons retain disconnect. The behavior applies to Codex, Claude Code, IBM Bob and configured Generic MCP connections.
- Add explicit retry, connect and disconnect labels and tooltip instructions, including keyboard access.
- Keep **Contextory: Disconnect an Agent** available for deliberately removing a configured connection while its indicator is gray.
- Clarify that current-service MCP observations, hook observations and native hook approval are separate. Historical MCP traffic or a current hook event alone does not turn the MCP indicator green.

See the [commit comparison](https://github.com/igormicadei/Contextory/compare/v0.5.0...v0.5.1) and [connection guidance](../USER-GUIDE.md#resume-an-existing-chat).

## Install or upgrade

1. Use Windows, Node.js **24+**, and VS Code **1.96+** or IBM Bob with one trusted local project folder.
2. Download `contextory-workspace-0.5.1.vsix` and `contextory-workspace-0.5.1.sha256` from the [GitHub release](https://github.com/igormicadei/Contextory/releases/tag/v0.5.1). Verify the VSIX SHA-256 against the checksum file.
3. Choose **Extensions > … > Install from VSIX…**, then reload the editor. VS Code users can run `code --install-extension .\contextory-workspace-0.5.1.vsix`.
4. If a connection is still waiting, run **Contextory: Check Native Connections**. Use **Contextory: Restart Agent Extensions** and retry a read-only `contextory_context_get` call in the native chat when needed. Native clients retain project and hook trust; unchanged approvals do not prove that an event was successfully delivered.

Existing project records are retained. This patch includes all 0.5.0 capabilities and requires no project-data migration.

## Validation and limits

The UI regression checks actual connect/disconnect messages for gray historical traffic, gray hook-only observations, green MCP observations and unconfigured agents, within the **32-test UI suite**. Release qualification includes TypeScript, canonical skills, backend tests, complete documentation and the extracted VSIX in isolated VS Code and IBM Bob profiles. See the [validation record](../VALIDATION.md).

Retry reapplies connection setup; it does not force a native MCP reload or approve hooks. This release fixes the incorrect disconnect action and does not claim to resolve every cause of missing native traffic. Native chat webviews and hook trust approval remain outside automated qualification. Distribution uses GitHub release assets; the project remains **UNLICENSED**.
