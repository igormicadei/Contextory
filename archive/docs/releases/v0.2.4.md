# Contextory 0.2.4

Keep a local record of the native agent model and observed usage alongside tracked work.

- Capture Codex `PostModelRequest` token fields when supplied, including input/output, cached input, reasoning and total tokens. Retain retries, request status, turn/session IDs and timestamps.
- Capture Claude's initial model and model changes. `PostModelSwitch` requires Claude Code 2.1.251 or newer. Claude and Bob do not provide general token totals through their documented standard lifecycle hooks; unavailable data remains explicit.
- Inspect a spec's **Usage** tab, export request/spec usage summaries with the implementation report, or query the same records through `contextory_usage_get`.
- Associate usage only with an exact native session and one active spec lease. Keep unmatched, ambiguous, expired and parent-only subagent observations at project level.
- Keep capture local and bounded. Do not read transcripts, prompts, tool inputs/results or model errors, and do not infer account billing or subscription quota. Cached input and reasoning remain subsets of input and output respectively.

Install the local `contextory-workspace-0.2.4.vsix`, reload the editor and restart/reload the native agent so its managed hooks and MCP tool list refresh. The hook reminder supplies the native session ID for session attachment. Capture starts after upgrade; previous work is not backfilled. Ledger migration from 0.2.3 is additive.

Validation includes type checking, a production build, 34 backend tests and 11 UI tests. Fixtures exercise the actual hook launcher, MCP transport, record persistence, concurrent sessions, missing counters and report filtering. These tests do not establish live authenticated model-hook delivery in each native client.
