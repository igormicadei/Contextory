# Contextory v0.3.0

Understand the code around a request, explore it visually, and carry the same project context into your native agent or a standalone MCP client.

## In this release

- **Live codebase intelligence:** a persistent, rebuildable TypeScript/JavaScript and Python graph connects definitions, calls, imports, inheritance, tests, documentation and explicit project decisions. Saved-file changes refresh the graph automatically; source citations and coverage notices remain visible.
- **Visual Architecture explorer:** start with a subsystem map, drill into file shortcuts and symbols, and inspect a focused neighborhood. Breadcrumbs and Back preserve context. Filter relationship types and direction, open exact source locations, or use a directional dependency matrix to compare subsystem coupling.
- **Clearer Code map:** a stable layered diagram, coordinated step list and source inspector, typed connections, selected-path highlighting, relationship filters and focused neighborhoods. Zoom, pan and fit help navigate larger traces; direct incoming/outgoing steps make the next action clear.
- **Task context for agents:** ranked definitions and bounded relationships, source/record impact, shortest indexed paths and architecture summaries share the same MCP contracts in native and headless clients. Version 0.3.0 advertises 23 tools.
- **Portable agents:** canonical codebase/workflow skills and references, shared runtime guidance, ownership-aware workspace synchronization, generic MCP export, and a standalone CLI/stdio MCP server. Hooks add reminders and metadata; they are optional.
- **Optional Graphify import:** validated node-link JSON with explicit provenance and source-hash invalidation. Regenerate and re-import external analysis after its cited source changes.
- **Complete documentation:** searchable guides, architecture, tool and skill references, validation records and release history at [igormicadei.github.io/Contextory](https://igormicadei.github.io/Contextory/), deployed from the orphan `gh-pages` branch.

This release also includes automatic agent discovery and its pause switch, adaptive Panel layouts, workspace identity and native usage records introduced since the previous published release, 0.2.3.

## Install

1. Use **Windows**, **Node.js 24+**, and **VS Code 1.96+** or **IBM Bob** with one trusted local project folder.
2. Download `contextory-workspace-0.3.0.vsix` and `contextory-workspace-0.3.0.sha256` from the [release assets](https://github.com/igormicadei/Contextory/releases/tag/v0.3.0). Compare the package SHA-256 with the checksum file.
3. Choose **Extensions → … → Install from VSIX…**, select the package, and reload the editor. VS Code users can also run `code --install-extension .\contextory-workspace-0.3.0.vsix`.
4. Open the project. Contextory prepares detected native-agent bridges; review and trust/reload their MCP configuration through the native clients.

Install and authenticate your native agent separately. Python **3.10+** is needed only for Python analysis. Optional semantic search downloads its runtime/model separately; lexical/structural retrieval works without it. See the [user guide](../USER-GUIDE.md) and [standalone guide](../CODEBASE-INTELLIGENCE.md#run-without-an-editor).

## Upgrade and storage

The additive schema 4 migration preserves Contextory work records; the generated source graph can be rebuilt. Install over the same Contextory extension identity, reload the editor, and reload existing native MCP sessions to discover the new tools and managed skills. Back up editor-managed storage before upgrading.

Standalone mode uses a separate ledger in `<root>/.contextory-local/service` unless configured otherwise. Use a live editor descriptor to share editor records explicitly; no silent merge occurs. Back up standalone storage when it holds authoritative work.

Builds installed under the pre-Contextory identity still require disconnecting their agents before replacement. Their records remain in the former storage and are not imported automatically.

## Validation and limits

The [validation record](../VALIDATION.md) describes automated checks, source evaluation and extracted-package checks in VS Code **1.145.3** and IBM Bob (VS Code API **1.126.0**), along with retained qualification boundaries.

Static maps describe possible indexed relationships and control paths, rather than observed execution or test coverage. Search results and file shortcuts are bounded; use scoped queries and neighborhood exploration for additional detail. Reciprocal matrix entries indicate direct two-way dependencies, not exhaustive cycle detection. Graphify is an optional import format, with no bundled Graphify runtime.

Authenticated native-agent conversations, other operating systems, remote/multi-root workspaces, large-monorepo performance and universal language analysis remain unqualified. Distribution is through GitHub release assets; this does not publish to the VS Code Marketplace. The project remains **UNLICENSED**.
