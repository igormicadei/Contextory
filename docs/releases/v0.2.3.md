# Contextory v0.2.3

Contextory manages development requests and gives native agents shared project context. Keep chatting in Codex, Claude Code, or IBM Bob while the extension tracks requests, milestones, specs, findings, decisions, test evidence, and outcomes through MCP and lifecycle hooks.

## In this release

- **Contextory identity:** new name throughout the extension, commands, settings, MCP tools, hooks, skills, reports, and package.
- **Meaningful icon:** a request card connected to context nodes, shared across the activity bar, sidebar, and extension listing.
- **Live themes:** light, dark, custom, and both high-contrast modes across all views; switching themes preserves open requests and drafts.
- **Public documentation:** installation, everyday workflow, MCP tools, source flow/search, checks, reports, troubleshooting, and development/release instructions.

The native-agent foundation also includes request progress, pinned agent controls, full linked history, per-request reports/changelogs, Python and TS/JS flow maps, relationship exploration, local search, and verified agent-driven spec completion. Search and source mapping are available through agent tools as well as the UI.

## Install

1. Install **Node.js 24+** and use **VS Code 1.96+** or **IBM Bob** on Windows with one trusted local project folder.
2. Download `contextory-workspace-0.2.3.vsix` from the assets below.
3. In Extensions, open **… → Install from VSIX…**, select the package, and reload when prompted.
4. Open Contextory, connect your native agent, review/trust its project MCP/hook configuration, and reload its MCP session as needed.

Python tracing needs **Python 3.10+**. Optional local semantic search is prepared separately; no model is bundled in the VSIX. The `.sha256` asset contains the package's SHA-256 checksum.

## Upgrade note

The new extension identity is `contextory-local.contextory-workspace`; tools use `contextory_` and settings use `contextory.`. Disconnect a build installed under the former name before uninstalling it, then install Contextory and reconnect. Previous records stay in the former extension storage and are not imported automatically.

The project remains **UNLICENSED**. Third-party dependency notices are included in the package and repository.
