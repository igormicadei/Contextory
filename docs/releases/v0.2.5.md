# Contextory 0.2.5

Use Contextory horizontally in VS Code's Panel, identify the active workspace at a glance, and prepare your preferred native agent bridge at startup.

- Move **Workspace Tasks** to the Panel for a compact header/navigation row, side-by-side work and activity, a request list beside a specification inspector, and bounded history and source-flow views.
- Keep selected specs, detail tabs, expanded milestones, drafts and scroll positions when the view resizes. Narrow views retain the sidebar layout. Agent controls stay in the footer and live theme changes still apply.
- Show the workspace name in every header, including dedicated relationship and source-flow views; hover for its full path.
- Prepare MCP/hooks when Contextory is ready, before an agent session is required. `contextory.startupAgent` defaults to `last-used`, with workspace history taking precedence over the last agent used elsewhere. Choose `codex`, `claude`, `bob`, or `none` in Settings instead. A manual disconnect stays disabled in that workspace until reconnected.
- Retain the model/usage records introduced in 0.2.4, including the Usage tab and `contextory_usage_get` tool.

Install `contextory-workspace-0.2.5.vsix` and reload the editor. To dock horizontally, use the view header's **Move View → Panel** or **Move View…** menu. Horizontal layout activates at 760 pixels wide and a 3:2 aspect ratio; narrow/tall views use the sidebar layout. Source tracing in very short panels keeps a minimum diagram area and allows the content to scroll.

Startup prepares Contextory's local service and project integration. The native agent still owns its session, trust and MCP reload. The green light indicates observed MCP traffic. This local package does not publish a Marketplace extension or a GitHub release.

Validation: TypeScript checking, production builds, 38 backend tests and 19 Playwright tests. Visual review covers 760×260, 1280×420 and 1920×360 panels, Requests, loaded History, source flow, light and high-contrast themes, long workspace names and the 320-pixel sidebar. Provider-native authentication and trust/reload remain native-client responsibilities.

The extracted VSIX also passed the full host checks in VS Code 1.145.3 and IBM Bob (VS Code API 1.126.0), including automatic startup MCP/hook preparation before opening Contextory or starting a native session.
