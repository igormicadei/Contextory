# Contextory v0.4.0

Map other local codebases alongside your current application. Reference repositories help developers and agents understand an existing architecture, investigate migration sources and learn implementation patterns while keeping the active project's source graph and work records separate.

## Changes

- Use **Architecture → Add reference** to register up to eight local codebases. Choose a repository in **Codebase** to explore its subsystem map, entry points, symbols and connections. The sidebar and Architecture workbench keep independent selections for side-by-side exploration.
- Keep each reference in a separate persistent source index and analysis worker. Registrations survive restarts; queries for different repositories can run concurrently. Analysis writes no source, configuration, requirements or checks into the reference.
- Give agents `contextory_codebase_list` and `contextory_codebase_change`, plus explicit `codebaseId` selection on architecture, context, search, impact, path, index/import and flow trace/expand tools. Omitted or `current` always selects the active project. Responses identify the reference root so same-path symbols remain distinguishable.
- Add CLI `references`, `reference-add`, `reference-remove` and source-command `--codebase` selection. Update portable skills and shared native/headless guidance with reference scope, freshness and citation rules.
- Scope source navigation and flow tracing to the selected repository, reject responses from previous selections, and keep current-project unsaved editor buffers out of reference analysis. **Detach reference** leaves its source untouched and retains rebuildable cached projections under the owning service storage.
- Support long Windows editor-storage paths when opening SQLite ledgers and reference projections.

Understanding a reference does not automatically apply its design, change requirements or migrate code. Ask the agent explicitly when you want to implement something in the current application. See the [reference-codebase guide](../CODEBASE-INTELLIGENCE.md#analyze-reference-codebases) for agent and CLI examples.

## Install or upgrade

1. Use Windows, Node.js **24+**, and VS Code **1.96+** or IBM Bob with one trusted local project folder.
2. Download `contextory-workspace-0.4.0.vsix` and `contextory-workspace-0.4.0.sha256` from the [GitHub release](https://github.com/igormicadei/Contextory/releases/tag/v0.4.0). Compare the package SHA-256 with the checksum file.
3. Choose **Extensions → … → Install from VSIX…**, select the package and reload the editor. VS Code users can run `code --install-extension .\contextory-workspace-0.4.0.vsix`.
4. Reload existing native MCP connections or restart their sessions to discover the updated tool catalog. Native agents keep their own permissions and authentication.

Existing schema 4 project records remain compatible. References are registered in the owning workspace service and indexed under its storage; no separate editor workspace or companion installation is needed in the reference. Keep using the same storage or editor descriptor with the standalone CLI. Python 3.10+ is needed for Python analysis.

## Validation and limits

Validation includes **63 backend tests**, **29 UI tests**, typechecking, canonical/workspace skill checks and a complete **23-page** documentation build. Extracted-package scenarios pass in VS Code **1.145.3** and IBM Bob, VS Code API **1.126.0**, including same-path unsaved-buffer isolation and unchanged reference source after detachment. See the [validation record](../VALIDATION.md).

References refresh saved files on demand; cached architecture is explicit. Reference search uses lexical graph matching, with a reported lexical fallback for hybrid mode. Existing TS/JS, Python and optional Graphify coverage limits apply independently to each repository. Static relationships describe possible connections, not observed execution or test coverage. Remote cloning, automatic cross-repository graph edges/migration, authenticated-model conversations, other operating systems and large-repository performance are not qualified by this release.

Browse the [complete documentation](https://igormicadei.github.io/Contextory/) for user guides, tools and portable skills. Distribution uses GitHub release assets. The project remains **UNLICENSED**.
