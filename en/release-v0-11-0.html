Contextory / Release v0.11.0

Release v0.11.0

    Decide from a clear explanation

    Approval cards ask the agent to explain what changes, why approval is needed and how application behavior changes. Approve or Reject needs no comment. Request changes accepts instructions, keeps implementation blocked and lets the agent update the same proposal before another decision. Historical before/after definitions, actors, hashes and rationale remain indexed.

    Readable source snapshots refresh automatically without a user comment or implicit approval. Missing references, concurrent edits and changed targets remain protected. Optional baseline review starts collapsed and can be opened with a click or keyboard; its chosen state survives refresh and navigation. Pending approval decisions remain visible.

    Keep the originating conversation

    The project, provider and exact native session are retained on linked work and proposals. Durable approval/rejection/feedback replies return only to that session through trusted hooks. A waiting hook can return the response within a four-minute budget; expiry or service failure never grants approval. Queued/offered/unbound status distinguishes transport from model execution.

    Reopen conversation uses the installed Claude session command. Codex resumes the exact saved conversation in an interactive terminal and requires its CLI. Bob/generic clients or unavailable adapters copy the session ID for native history recovery. A stopped or untrusted client may need manual resume; unknown historical session identities are never guessed. Native permissions, sign-in and history availability stay with the client.

    Install and verify

    Download contextory-workspace-0.11.0.vsix and the matching .sha256, compare the SHA-256, then use Extensions > Install from VSIX. Reload the editor and native integrations when prompted so the new tool contracts and waiting hooks are discovered. Review hook trust in the native client. English and Brazilian Portuguese follow the VS Code display language, including instructions for new agent-authored UI entries.

    Download the 0.11.0 release

    Qualification covers approval behavior and source history, live waiting-hook responses, service/headless/registration boundaries, English/Portuguese UI, keyboard collapse/recovery, bilingual documentation, canonical skill consistency and package checksums. Trusted local Windows workspaces with Node.js 24+ remain the qualified environment. Authenticated live model conversations retain their native-client limits.
