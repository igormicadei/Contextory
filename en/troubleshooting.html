Troubleshooting and recovery

    Recover service and native connections

    SymptomAction
    Service unavailableKeep the project editor open, check Node 24+ in its PATH, set contextory.nodeExecutable if needed and inspect Output > Contextory
    Analysis or connection disabledTrust a supported local workspace; avoid virtual/remote or nested project roots
    Gray agent lightHover for configuration/traffic state, click to retry setup, review native MCP/hook trust and make a read-only call
    Tools missing in an old chatRestart agent extensions, reload the native MCP connection and reopen the chat as required by that client
    Hooks remain unobservedRebuild once, inspect repaired files, then check native trust and trigger a supported lifecycle event; unchanged files are not execution evidence
    Unowned or malformed configurationResolve the concrete conflict; registration preserves unowned entries and refuses linked paths
    Older service after an upgradeFollow the mismatch message; close project editors for about 65 seconds before reopening when requested

    Recover source results and completion

    SymptomAction
    Python flow failsCheck Python 3.10+ and contextory.pythonExecutable; use an absolute executable path if needed
    Unexpected source rootSet projectId/codebaseId explicitly and focus the intended editor symbol before tracing
    Source search seems staleRe-query saved source; refresh an empty/failed index, inspect exclusions and regenerate/re-import stale Graphify data
    Semantic search unavailablePrepare the optional local runtime and index, or use lexical/hybrid fallback
    Spec stays submittedPoll check jobs, resolve blockers and stale evidence, submit every criterion mapping, then explicitly complete using the returned revision
    Cross-project group incompleteRestore missing/offline workspace members and recover missing branches on the original owner; verify each local request

    Report a reproducible issue

    Include Contextory version, editor/version, Node/Python versions, exact error text and reproduction steps. Remove credentials, private descriptors, tokens and project-private records before sharing logs. Preserve current coverage and unverified limits.
