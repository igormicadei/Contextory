# Loading

Two-arc stroked circle rotating on the productive easing curve at 690ms — no pulsing, no bounce. `withOverlay` blocks the page for a full-route load.

```jsx
<Loading withOverlay description="Provisioning instance" />
```

| Prop | Type | Default |
|---|---|---|
| `small` | `boolean` | `false` |
| `withOverlay` | `boolean` | `false` |
| `description` | `string` | `'Loading'` |
