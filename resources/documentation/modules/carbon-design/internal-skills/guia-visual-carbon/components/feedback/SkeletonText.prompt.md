# SkeletonText

Flat placeholder bars with a slow shimmer. Match the skeleton's shape to the real content so layout doesn't jump when it arrives.

```jsx
<SkeletonText heading width="60%" />
<SkeletonText paragraph lineCount={4} />
```

| Prop | Type | Default |
|---|---|---|
| `heading` | `boolean` | `false` |
| `paragraph` | `boolean` | `false` |
| `lineCount` | `number` | `3` |
| `width` | `string` | `'100%'` |
