# Search

The clear button only appears once there is a value, and is separated from the field by a 1px rule.

```jsx
<Search labelText="Search resources" placeholder="Search resources" />
```

| Prop | Type | Default |
|---|---|---|
| `labelText` | `string` | `'Search'` |
| `placeholder` | `string` | `'Search'` |
| `size` | `'sm' \| 'md' \| 'lg'` | `'lg'` |
| `disabled` | `boolean` | `false` |
| `onChange` | `(e) => void` | — |
| `onClear` | `() => void` | — |
